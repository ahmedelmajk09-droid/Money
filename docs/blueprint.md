# **App Name**: Gilded Pulse

## Core Features:

- Hybrid Portfolio Dashboard: Display a glassmorphic dashboard tracking cash, debts, and bills with a master 'Total Balance' calculated from dynamic gold gram conversion.
- Smart Growth Advisor: An AI advisor tool that evaluates current gold market trends against your debt portfolio to suggest optimal repayment strategies.
- Bilingual Debt Ledger: Log debts in both Cash (EGP/USD) and Gold (Grams) with automatic calculation of gains or losses relative to purchase price.
- Centralized Persistence: Migrate logic from local storage to a centralized cloud database for multi-platform sync and data safety.
- Interactive Bill Manager: A focused interface for monthly bills tracking with check-and-clear functionality for effective budget control.
- Asset Flux Calculator: Calculate live gains or losses based on the delta between entry goldPrice and real-time market valuations.
- Dynamic Balance Tool: Generates simulated wealth forecasts using an LLM to predict balance based on user spending habits and gold volatility.

## Style Guidelines:

- Primary color: Electric Indigo (#687FEF) chosen for a tech-focused and deep-space aesthetic that pairs with the wealth management theme.
- Background color: Deep Obsidian (#0F1117), a heavily desaturated blue-tinged dark mode surface.
- Accent color: Celestial Azure (#19B7E6) for highlight states and checkmarks, providing sharp contrast against the dark background.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact headlines to provide a computerized tech feel, with 'Inter' (sans-serif) for clean and objective body text.
- Lucide/Feather icons for a minimalist, ultra-modern finance aesthetic.
- Responsive grid of glassmorphic cards utilizing radial gradients and blurred backdrops (frosted glass effect).
- Smooth counter-animations for total balance updates and subtle pulse effects on gain/loss indicators.
